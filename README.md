# IT Help Desk Triage Lite

## Full Software Development Lifecycle (SDLC) Project

### Overview
This project implements a simplified IT Help Desk Triage system designed to manage, prioritize, and process support tickets efficiently. The system was developed following a full Software Development Lifecycle (SDLC) approach, incorporating requirements engineering, system design, implementation, testing, dependability enhancements, deployment planning, and maintenance strategies.

## System Features
- Ticket submission with category and urgency selection  
- Automated priority calculation using weighted logic  
- Duplicate ticket detection using keyword and time-based rules  
- Secure access control and validation  
- Report generation with supported output formats (CSV, XLSX)  
- Error handling and input validation for system reliability
